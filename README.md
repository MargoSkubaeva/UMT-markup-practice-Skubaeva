# Flora Workshop

Responsive flower shop landing page with interactive sliders, modal windows and bouquet catalog.

### Implemented Functionality

- Responsive layout for Mobile (375px), Tablet (768px) and Desktop (1440px)
- Mobile burger menu
- Bestsellers slider with:
  - navigation arrows
  - pagination bullets
  - swipe support
- Feedback slider using Swiper.js
- Dynamic bouquet loading from API
- "Show More" button for bouquets section
- Bouquet details modal window
- Order modal form
- Notifications for user actions
- Smooth animations using AOS
- Retina image support (1x / 2x)
- Custom favicon
- BEM methodology
- SCSS architecture
- Adaptive images and responsive design

## Technologies

- HTML5
- CSS
- SCSS
- JavaScript
- Swiper.js
- AOS
- REST API
